Password Strength Analyzer
A Python-based cybersecurity project that evaluates
password strength and provides security recommendations.

Project Overview
This application evaluates user-entered test passwords
using five basic security checks.

It includes a command-line interface (CLI) and a
Tkinter graphical user interface (GUI).

Key Features
Password length validation
Uppercase and lowercase character detection
Numeric character detection
Special character detection
Common password detection
Password strength classification
Security recommendations
Colour-coded password strength indicator
Technologies Used
Python
Tkinter
Regular Expressions (re)
Visual Studio Code
Git and GitHub
Running the Application
Command-line version:

python password_analyzer.py
Graphical version:

python password_gui.py
Use a working Python installation if the python
command is unavailable.

Security Limitations
This application is an educational password-strength
checker. Its scoring system does not guarantee that
a password is secure.

Only use fictional test passwords when demonstrating
the application.
